# Selectel models for OpenCode

Серверный плагин для OpenCode. Обновляет каталог моделей и цены Selectel в работающем OpenCode, сохраняя ручные настройки в `opencode.json`.

Два источника:

- `https://api.selectel.ru/aig/v1/models` — наличие моделей, имена, цены, лимиты, модальности и поддержка инструментов.
- `https://github.com/anomalyco/models.dev/tree/dev/providers/openrouter/models` — поддержка reasoning, уровни effort и возможность отключения. Плагин загружает архив ветки `dev` с `codeload.github.com`, читает только TOML из этого каталога и использует ETag для повторных проверок.

## Требования

- OpenCode 2.2 или новее. Проверен на SDK `@opencode/plugin` 2.2.0–2.4.1; версии 2.0 и 2.1 не поддерживаются.

## Установка

```sh
opencode plugin add "github:perminovsi/opencode-selectel-models#semver:^1.0.0"
```

Команда добавляет плагин в глобальный `~/.config/opencode/opencode.json`. Диапазон `semver:^1.0.0` означает, что OpenCode сам проверяет обновления при старте и раз в 24 часа и ставит новые версии 1.x. Проверить и обновить вручную можно командами `opencode plugin check` и `opencode plugin update`.

## Подключение

Выполните `/connect`, выберите Selectel и введите API-ключ. Один ключ используется обоими провайдерами, `selectel` и `selectel-anthropic`. Плагин создаёт их сам, поэтому добавлять их в `opencode.json` не нужно. Если провайдер всё же объявлен в `opencode.json`, плагин использует это объявление.

Без подключения провайдеры не появляются в списке, а статус показывает подсказку `/connect`. Модели появятся после первой синхронизации. Ключи из `settings.apiKey` плагин не читает, а другие провайдеры и их подключения не меняет.

## Опции

Опции необязательны. По умолчанию `autoRefresh: true` и `refreshIntervalMs: 21600000`. Команда `opencode plugin add` записывает в `plugins` только строку с пакетом. Чтобы задать опции явно, замените строку на объект:

```jsonc
{
  "plugins": [
    {
      "package": "github:perminovsi/opencode-selectel-models#semver:^1.0.0",
      "options": {
        "autoRefresh": true,
        "refreshIntervalMs": 21600000
      }
    }
  ]
}
```

Дополнительная опция `metadataAliases` описана в разделе «Правила обновления».

## Разработка

Для работы с локальной копией установите зависимости и проверьте проект:

```sh
npm ci --ignore-scripts
npm test
npm run typecheck
```

Чтобы OpenCode загружал локальную копию вместо опубликованной, укажите путь в `opencode.json`:

```jsonc
{
  "plugins": ["/path/to/opencode-selectel-models"]
}
```

`@opencode/plugin` предоставляет сам OpenCode во время загрузки, поэтому в обычной установке он не нужен.

## Использование

- `/selectel-models-update` — немедленно запросить оба источника и обновить каталог.
- `/selectel-models-status` — показать число моделей, время обновления, ошибки, использование кэша и ID без метаданных OpenRouter.
- RPC `selectel-models.refresh` и `selectel-models.status` — те же действия для других плагинов и клиентов; оба принимают `{}`.

При включённом `autoRefresh` обновление запускается в фоне при загрузке плагина, затем каждые 6 часов по умолчанию. Смена или обновление ключа также запускает проверку. Ручные команды работают и с `autoRefresh: false`.

Команды регистрируются только в терминальном интерфейсе: они показывают диалог и не добавляют служебные сообщения в контекст модели. Для вызовов через API используются RPC-методы, чтобы не создавать дубли slash-команд.

Для вызова RPC через CLI укажите рабочую директорию OpenCode:

```sh
opencode api post /api/rpc/selectel-models/status \
  --param 'location[directory]=/path/to/project' --data '{"input":{}}'
```

## Правила обновления

- В каталог попадают модели, у которых среди выходных модальностей есть `text`. Модели только с изображениями, видео и другими модальностями пропускаются.
- Модели `anthropic/*` попадают в `selectel-anthropic`, остальные — в `selectel`.
- Anthropic-модели получают ID вида `claude-sonnet-5-5`. Если Selectel объявляет такой алиас, запросы идут по нему. Иначе используется канонический ID из API, например `anthropic/claude-sonnet-5.5`.
- Цены на вход, выход, чтение и запись кэша пересчитываются в цену за миллион токенов без округления. Валюта остаётся как у Selectel. Тарифы для аудио и изображений отдельно не хранятся: в OpenCode для них нет полей.
- Уровни reasoning берутся из метаданных models.dev, то есть из OpenRouter. Плагин не делает платных запросов, чтобы проверить каждый уровень на маршруте Selectel. Уже существующие варианты сохраняются как есть, новые добавляются к ним. Для OpenAI-compatible провайдера уровень `none` отправляет `reasoning_effort: "off"`. Anthropic получает нативные `thinking` и `effort`.
- Из Selectel обновляются список моделей, имена, лимиты контекста и вывода, модальности, поддержка tools и цены.
- Ручные значения сохраняются для моделей, которые уже известны плагину: `settings`, `headers`, `body`, `enabled`, `status`, варианты, дата выпуска.
- Модели, которых нет в ответе Selectel, убираются из рабочего реестра.
- `opencode.json` плагин не меняет. После отключения плагина модели, которые он добавил, пропадают: в конфиг они не записываются.
- При сетевой ошибке или некорректном ответе сохраняется последняя успешная версия. Ошибка models.dev не мешает обновлению цен и списка Selectel. Кэш хранится в хранилище плагина, ключей в нём нет, и привязан к отпечатку ключа: при смене аккаунта он не переносится.

При несовпадении ID можно явно задать соответствие:

```jsonc
{
  "plugins": [{
    "package": "github:perminovsi/opencode-selectel-models#semver:^1.0.0",
    "options": {
      "metadataAliases": {
        "selectel/my-model": "vendor/exact-model-id"
      }
    }
  }]
}
```

Если метаданных для ID с суффиксом OpenRouter `:exacto` или `:extended` нет, берутся данные базового ID без суффикса. Встроены точные соответствия для `reka/reka-edge`, `sakana/namazu`, `selectel/deepseek-v4-flash`, `selectel/glm-5.3-flash` и `selectel/qwen3.8-27b`. Похожие названия семейств автоматически не сопоставляются.
