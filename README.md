# Selectel models for OpenCode

Серверный плагин для OpenCode **2.2.7+**. Обновляет каталог моделей и цены в работающем OpenCode, сохраняя ручные настройки в `opencode.json`.

Два источника:

- `https://api.selectel.ru/aig/v1/models` — наличие моделей, имена, цены, лимиты, модальности и поддержка инструментов.
- `https://github.com/anomalyco/models.dev/tree/dev/providers/openrouter/models` — поддержка reasoning, уровни effort и возможность отключения. Плагин загружает архив ветки `dev` с `codeload.github.com`, читает только TOML из этого каталога и использует ETag для повторных проверок.

## Подключение

Подключение и серверные параметры задаются в `~/.config/opencode/opencode.json`. OpenCode автоматически передаёт TUI-часть подключённого плагина в CLI; отдельная запись в `cli.json` не требуется.

```jsonc
{
  "plugins": [
    {
      "package": "./plugins/selectel-models",
      "options": {
        "autoRefresh": true,
        "refreshIntervalMs": 21600000
      }
    }
  ]
}
```

Провайдеры `selectel` и `selectel-anthropic` должны быть объявлены в конфигурации. Плагин использует их активные ключи из `/connect` и не меняет подключения, адреса API или другие провайдеры. Ключи из `settings.apiKey` отдельно не читаются: используйте подключение OpenCode.

Установить зависимости локального плагина:

```sh
cd ~/.config/opencode/plugins/selectel-models
npm ci --omit=dev --ignore-scripts --legacy-peer-deps
```

OpenCode предоставляет `@opencode/plugin` во время загрузки. Для разработки используйте обычное `npm ci --ignore-scripts`, затем `npm test` и `npm run typecheck`.

## Использование

- `/selectel-models-update` — немедленно запросить оба источника и обновить каталог.
- `/selectel-models-status` — показать число моделей, время обновления, ошибки, использование кэша и ID без метаданных OpenRouter.
- RPC `selectel-models.refresh` и `selectel-models.status` — те же действия для других плагинов и клиентов; оба принимают `{}`.

При включённом `autoRefresh` обновление запускается в фоне при загрузке плагина, затем каждые 6 часов по умолчанию. Смена или обновление ключа также запускает проверку. Ручные команды работают и с `autoRefresh: false`.

Команды регистрируются только в терминальном интерфейсе: они показывают диалог и не добавляют служебные сообщения в контекст модели. Для вызовов через API используются RPC-методы, чтобы не создавать дубли slash-команд.

Для вызова RPC через CLI укажите рабочую директорию OpenCode:

```sh
opencode api post /api/rpc/selectel-models/status \
  --param 'location[directory]=/path/to/project' --data '{"input":{}}'
```

## Правила обновления

- Сохраняется прежний охват: модели с `text` среди выходных модальностей. Чистые image, video и decision модели не добавляются.
- Все `anthropic/*` попадают в `selectel-anthropic`, остальные — в `selectel`.
- У Anthropic сохраняются ID вида `claude-sonnet-5-5`. Если Selectel не объявляет такой алиас, в запросе используется канонический ID из API.
- Цены на вход, выход, чтение и запись кэша пересчитываются с одного токена на миллион без округления до двух знаков. Валюта остаётся такой, как в Selectel. Поля OpenCode не позволяют отдельно хранить тарифы аудио, изображений и других модальностей.
- Прежние варианты reasoning сохраняются целиком; новые уровни дополняют их. Для OpenAI-compatible провайдера вариант `none` отправляет `reasoning_effort: "off"`, согласно документации Selectel. Anthropic использует нативные `thinking` и `effort`.
- Уровни берутся из OpenRouter в `models.dev`. Плагин не выполняет платные генерации для проверки их поддержки каждым маршрутом Selectel.
- Сохраняются ручные `settings`, `headers`, `body`, состояние `enabled`, варианты и даты уже известных моделей. Доступность, цены, лимиты, модальности и tools обновляются из Selectel.
- Исчезнувшие из API модели убираются из рабочего реестра. Исходный JSON не переписывается: отключение плагина возвращает статический каталог.
- При сетевой ошибке или некорректном ответе сохраняется последняя успешная версия. Ошибка получения `models.dev` не мешает обновлению цен и списка Selectel. Кэш хранится в штатном хранилище плагина; ключей в нём нет. Каталоги привязаны к отпечатку ключа и не переносятся между аккаунтами.

При несовпадении ID можно явно задать соответствие:

```jsonc
{
  "plugins": [{
    "package": "./plugins/selectel-models",
    "options": {
      "metadataAliases": {
        "selectel/my-model": "vendor/exact-model-id"
      }
    }
  }]
}
```

Для `:exacto`/`:extended` используется описание базового ID. Встроены точные соответствия для `reka/reka-edge`, `sakana/namazu`, `selectel/deepseek-v4-flash`, `selectel/glm-5.3-flash` и `selectel/qwen3.8-27b`. Похожие названия семейств автоматически не сопоставляются.
